# rust的web开发分支


Rust 共同基础
```
所有权 / 借用 / 生命周期 / 类型系统 / 错误处理
trait / 泛型 / 并发基础 / Cargo / 测试
│
├─ ① 网络服务与后端
│     API 服务、网关、协议服务、分布式系统
│
├─ ② 单片机与固件                 ← 你的当前主线
│     MCU 裸机、外设驱动、设备控制、嵌入式任务调度
│
├─ ③ 操作系统与底层系统
│     内核、设备驱动、Bootloader、系统运行时
│
├─ ④ 命令行与开发工具
│     CLI、自动化工具、构建工具、代码分析工具
│
├─ ⑤ 桌面应用与跨语言组件
│     桌面软件、原生库、供其他语言调用的高性能模块
│
├─ ⑥ WebAssembly
│     浏览器模块、沙箱执行、跨平台组件
│
├─ ⑦ 图形、游戏与计算
│     渲染、游戏引擎、图像处理、计算密集型模块
│
└─ ⑧ 数据与基础设施
      数据库、存储引擎、查询引擎、消息与网络基础设施

```

| 分支            | 对嵌入式的价值                 | 值得关注的库或工具                             | 你的学习安排       |
| ------------- | ----------------------- | ------------------------------------- | ------------ |
| ① 网络服务与后端     | 设备联网，以及上位机、网关与设备之间的通信   | 固件网络可关注 embassy-net；上位机服务有需求时再学 Tokio | 串口和基础外设之后    |
| ③ 操作系统与底层系统   | 固件启动、异常、中断、CPU 核心外设访问   | Cortex-M 上的 cortex-m、cortex-m-rt      | 当前阶段需要理解     |
| ④ 命令行与开发工具    | 编写设备测试、参数配置、数据采集工具      | 电脑端串口库 serialport                     | 学 UART 时配套使用 |
| ⑤ 桌面应用与跨语言组件  | 接入已有 Python、C/C++、Qt 工程 | PyO3、cbindgen                         | 有集成需求时学      |
| ⑥ WebAssembly | 某些浏览器配置界面或共享逻辑场景        | 暂不指定                                  | 不是当前前置       |
| ⑦ 图形、游戏与计算    | 小屏幕显示、图形界面、设备端计算        | 显示先关注 embedded-graphics               | 有屏幕或算法任务时学   |
| ⑧ 数据与基础设施     | 设备消息编码、配置与状态数据处理        | serde、postcard                        | 写通信协议时学      |
